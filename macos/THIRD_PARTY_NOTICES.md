# 第三方资源声明

## Node.js

GitHub Release 安装包内置从 [nodejs.org](https://nodejs.org/) 官方发行包取得的 Node.js 运行时。Node.js 及其随附组件依照各自的开源许可证分发；对应发行版的完整许可文本保存在 App 内的 `Contents/Resources/runtime/NODE_LICENSE`。

## JavaScript 开源依赖

本项目使用 React、AntV G2、Phosphor Icons、Vite、Model Context Protocol SDK、Zod 及其传递依赖。精确版本记录在 `package-lock.json` 与 `ui/package-lock.json` 中；各组件依照其仓库和 npm 包中声明的许可证使用。
